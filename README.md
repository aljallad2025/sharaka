# شراكة | Sharaka — تطبيق استثمار جماعي بالأسهم

منصة استثمار جماعي بالأسهم (Equity Crowdfunding) تربط أصحاب المشاريع بالمستثمرين في سلطنة عُمان والخليج.

## ⚠️ ملاحظة تنظيمية مهمة
هذا المشروع تقنياً جاهز، بس تشغيله الفعلي كمنصة أسهم حقيقية بيحتاج **ترخيص من هيئة سوق المال العُمانية (CMA)**
قبل استقبال أي أموال حقيقية. استشر محامي مختص بأسواق المال قبل الإطلاق التجاري.

## 📱 حالة المشروع الحالية
تم بناء **كل شاشات التطبيق (UI كامل)** بواجهات جاهزة وبيانات تجريبية (mock data)، بدون ربط فعلي بـ Supabase بعد.
كل نقاط الربط بالباك-إند محددة بتعليقات `// TODO:` بالكود عشان تكون واضحة لمرحلة الربط القادمة.

### الشاشات المبنية (13 شاشة)
- Splash + Onboarding (3 صفحات)
- اختيار نوع الحساب / تسجيل دخول / إنشاء حساب
- توثيق الهوية (KYC)
- **المستثمر**: استكشاف المشاريع، تفاصيل المشروع، شاشة الاستثمار، المحفظة
- **صاحب المشروع**: لوحة التحكم، قائمة المشاريع (تبويبات)، إضافة مشروع (4 خطوات)، متابعة التمويل
- **مشتركة**: الإشعارات، الملف الشخصي
- **الإدارة**: لوحة اعتماد المشاريع وطلبات التوثيق

## 🎨 الهوية البصرية
تصميم داكن فخم (Dark Premium) بلمسات ذهبية متدرجة، خط Cairo، دعم كامل لـ RTL.
**الشعار حالياً placeholder (أيقونة مصافحة)** — أرسللي ملف الشعار الرسمي (SVG/PNG بخلفية شفافة) لاستبداله بكل الشاشات.

## 🛠 خطوات التشغيل محلياً

```bash
# 1. توليد مجلدات android/ios (لازم تسويها لأن السلبوكس ما فيها Flutter SDK)
flutter create . --project-name sharaka --org com.superai

# 2. تثبيت الحزم
flutter pub get

# 3. تشغيل على المحاكي/الجهاز
flutter run
```

## 🔗 ربط Supabase (الخطوة القادمة)
1. أنشئ مشروع Supabase جديد
2. جهّز الجداول: `profiles`, `projects`, `investments`, `notifications`
3. فعّل Row Level Security (RLS) على كل جدول
4. عبّي بيانات الاتصال بـ `lib/main.dart` (مكان الـ TODO)
5. أضف حزمة `supabase_flutter` (موجودة مسبقاً بـ pubspec.yaml)

## 🏗 البناء عبر Codemagic
ملف `codemagic.yaml` جاهز بالمشروع — بس اربط الريبو بـ Codemagic وشغّل workflow `sharaka-android`
لتحصل على APK وAAB جاهزين تلقائياً.

## 📦 هيكلية المشروع
```
lib/
  core/          # الثيم، الألوان، الراوتر، البيانات التجريبية
  models/        # موديلات المستخدم، المشروع، الاستثمار
  screens/       # كل شاشات التطبيق مقسّمة حسب الدور
  widgets/       # مكونات مشتركة (بطاقة مشروع، أزرار، حقول إدخال)
```
